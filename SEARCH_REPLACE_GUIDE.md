# AURA COMMERCE - CJ Connection Search & Replace Guide

To ensure the legacy **Aura Gateway** is completely bypassed, follow these steps to find and replace all problematic code patterns.

### 1. Identify Legacy Gateway Callers
Run these `grep` commands in your terminal to find all files calling the old proxy or gateway:

```bash
# Find all files mentioning the Aura Gateway or Handshaking
grep -rnE "Aura Gateway|Handshaking" . --exclude-dir={node_modules,dist,.next}

# Find all files with hardcoded cjdropshipping.com URLs (dangerous)
grep -rn "cjdropshipping.com" . --exclude-dir={node_modules,dist,.next}

# Find all fetch calls that target the old proxy
grep -rn "cj-proxy" . --exclude-dir={node_modules,dist,.next}
```

### 2. Patterns to Replace

**LEGACY PATTERN (BROKEN):**
```typescript
// ❌ Calls the internal gateway that returns HTML 404
const response = await fetch('/api/aura-gateway/connect', { ... });
```

**FIXED PATTERN (DIRECT):**
```typescript
// ✅ Calls the dedicated CJ connecting route
const response = await fetch('/api/cj/connect', { method: 'POST', ... });
```

### 3. Replace in `AdminTab.tsx`
Replace the entire `handleEstablishConnection` function with a call to the new `CJConnectionPanel` component or use the direct `/api/cj/connect` fetch as shown in the new component code.

### 4. Verification
After replacing, ensure that `cj-url-audit.txt` (generated by `bash find-broken-cj.sh`) contains:
- ZERO instances of hardcoded `api.cjdropshipping.com` in UI components.
- ZERO references to non-existent `/api/aura-gateway` paths.

### 5. Final Check
Ensure your `.env` file on Vercel has these EXACT keys:
- `CJ_BASE_URL=https://developers.cjdropshipping.com/api2.0/v1`
- `CJ_EMAIL=your-email@example.com`
- `CJ_API_KEY=your-actual-api-key`
